# 🛡️ میانجی اسکرو (Mianji Escrow)

پلتفرم امن واسطه‌گری برای معاملات فریلنسری و دیجیتال در بستر تلگرام، قدرت گرفته از گوگل فایربیس.

## 🚀 راهنمای استقرار در Render (Deployment)

برای اینکه برنامه شما در **Render** به درستی کار کند، باید متغیرهای زیر را در بخش **Environment Variables** پنل رندر وارد کنید:

### ۱. متغیرهای حیاتی تلگرام
- `TELEGRAM_BOT_TOKEN`: توکن دریافتی از BotFather.
- `WEBAPP_URL`: آدرس نهایی سایت شما در رندر (مثلاً `https://mianji.onrender.com`).

### ۲. تنظیمات هوش مصنوعی
- `GEMINI_API_KEY`: کلید API گوگل جمینای برای بخش‌های هوشمند.

### ۳. تنظیمات فایربیس (Firebase)
برنامه به صورت خودکار از فایل `firebase-applet-config.json` استفاده می‌کند. اطمینان حاصل کنید که این فایل در مخزن (Repository) شما موجود باشد.

---

## 🛠 قابلیت‌های کلیدی
- **امنیت سخت‌گیرانه (Fortress Security)**: استفاده از Firestore Security Rules برای جلوگیری از هک و دسترسی غیرمجاز.
- **پنل OLED Black**: طراحی مدرن و بهینه برای گوشی‌های موبایل.
- **ورود با تاییدیه تلگرام**: احراز هویت امن کاربران از طریق ربات تلگرام.
- **چرخه کامل اسکرو**: از ثبت درخواست تا تسویه نهایی و داوری اختلافات.
- **چت داخلی**: گفتگو پیرامون هر معامله به صورت مجزا با قابلیت ارسال فایل و صوت.

## 👨‍💻 راهنمای توسعه‌دهنده (Debug)
برای فعال‌سازی پنل دیباگ در حالت واقعی، روی لوگوی بالای صفحه ۵ بار کلیک کنید. در این حالت می‌توانید وضعیت‌های مختلف قرارداد را برای تست تغییر دهید.

---
**توجه امنیتی:** هیچ‌گاه کلیدهای خصوصی (Private Keys) خود را در کدهای فرانت‌اِند قرار ندهید. تمام عملیات‌های حساس مالی در سمت سرور (`server.ts`) و با نظارت قوانین امنیتی دیتابیس انجام می‌شود.
