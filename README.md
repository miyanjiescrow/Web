# 🛡️ میانجی اسکرو (Mianji Escrow)

پلتفرم امن واسطه‌گری برای معاملات فریلنسری و دیجیتال در بستر تلگرام.

## 🚀 شروع سریع

### ۱. استفاده در حالت نمایشی (Demo Mode)
اگر هنوز دیتابیس Supabase خود را راه‌اندازی نکرده‌اید، هنگام باز کردن برنامه، دکمه **"ورود به حالت نمایشی (Demo)"** را بزنید. در این حالت:
- نیاز به هیچ تنظیماتی ندارید.
- می‌توانید تمام بخش‌های پنل را تست کنید.
- اطلاعات به صورت محلی در مرورگر شما ذخیره می‌شود.

### ۲. اتصال به دیتابیس واقعی (Supabase)
برای استفاده عملیاتی:
1. در [Supabase](https://supabase.com) یک پروژه بسازید.
2. اسکریپت SQL موجود در `.aistudio/artifacts/brain/.../supabase_schema.sql` را در SQL Editor سوپابیس اجرا کنید.
3. مقادیر `SUPABASE_URL` و `SUPABASE_KEY` را در بخش **Secrets** استودیو ای‌آی وارد کنید.

### ۳. هماهنگی با ربات تلگرام
برای اینکه ربات شما با این پنل کار کند، فایل `/docs/BOT_PROMPT.md` را مطالعه کنید.

## 🛠 قابلیت‌های کلیدی
- **پنل OLED Black**: طراحی مدرن و بهینه برای گوشی‌های موبایل.
- **TWA Auto-login**: ورود خودکار کاربران تلگرام بدون نیاز به رمز عبور.
- **چرخه کامل اسکرو**: از ثبت درخواست تا تسویه نهایی و داوری اختلافات.
- **چت داخلی**: گفتگو پیرامون هر معامله به صورت مجزا.

## 👨‍💻 راهنمای توسعه‌دهنده (Debug)
برای فعال‌سازی پنل دیباگ در حالت واقعی، روی لوگوی بالای صفحه ۵ بار کلیک کنید.
